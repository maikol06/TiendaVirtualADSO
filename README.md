# Tienda Virtual ADSO

## Objetivo
Desarrollar una tienda virtual que permita a los usuarios consultar productos y realizar compras de manera fácil y segura.

## Funciones principales
1. **Consultar productos:** los usuarios podrán ver los productos disponibles, sus precios y sus descripciones.
2. **Realizar compras:** los usuarios podrán seleccionar productos y hacer pedidos a través de la tienda virtual.
